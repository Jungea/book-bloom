# Library Tycoon — Cafe Library V2

Production PNG pack for the 640×360 logical room / 1280×720 2× source plan. Files are individual RGBA PNGs. `manifest.json` is the authoritative inventory and records actual pixel sizes.

## Placement

Use the bottom-center anchor for free-standing objects and align facility bases to logical Y=240 (native Y=480). The four single slots have logical centers 80, 240, 400, 560. Render at native resolution or an integer multiple with image smoothing disabled.

## Content separation

Empty shelves, display frames, front occluders, book spines, cover placeholders, screens, notice cards, trophies, chairs, and sign frames are separate files. Render dynamic text, covers, counts, dates, and progress in the application. `featured_display_empty` plus `promotion_sign_frame` supports monthly/new/recommended/theme displays without hard-coded marketing copy.

## Characters

Each character sheet is 256×192: four direction rows (down, left, right, up) × four 64×48 frames. Use `*_idle` with frame 0; advance `*_walk` at a game-defined cadence. Feet share the same baseline.

## Layer order

Background tiles → wall attachments → shadows → furniture bodies → characters behind front layers → front layers/books/content → UI/effects. Use `bookshelf_shadow` under shelving and the supplied `*_front_layer` images as occluders.

## Validation and license

Generated by the project build script as original geometric pixel artwork. No third-party art or text/cover imagery is bundled. The pack intentionally provides a café-like reading atmosphere only; it does not introduce a coffee sale, drink, or retail mechanic.
