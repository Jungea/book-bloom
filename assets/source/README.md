# BookBloom 원본 에셋

Google Drive의 도서관 타이쿤 에셋을 2026-11-26에 로컬로 가져왔다. Claude Code와 Codex는 이 폴더의 파일을 직접 참조한다.

| 경로 | 내용 |
| --- | --- |
| v1/ | 최초 MVP 에셋 |
| v2/ | 모던 카페형 도서관 에셋 |
| v3/ | 도식형 화면 재현 에셋 |
| v4/ | 첫 생성 이미지 기반 4슬롯 에셋과 manifest |
| archives/ | 각 버전 원본 ZIP과 V4 4슬롯 수정 전 백업 |

2026-11-26에 V4를 BookBloom의 초기 화면 에셋으로 선택했다. V4의 `manifest.json`은 34개 에셋을 참조하며 모두 로컬에 존재하는 것을 확인했다. 최종 논리 해상도, 개별 이미지의 실제 게임 적용 적합성은 PC·Android 검증 후 판단한다. 기존 버전 파일은 수정하지 않는다.
