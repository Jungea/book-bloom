# 03. 독서 관리 기획

> 확인: 2026-11-26
> 상태: 노션 원문 이관. 문서 안의 확정·제안·미정 표기를 그대로 따른다.

## 기능 초안

- 책 검색 및 등록
- 완독일, 독후감, 평점 기록
- 독후감에 따른 재고 보상은 확정 전이므로 적용하지 않음
- 책 클릭 시 기록 열람

## 도서 재고 및 대여 규칙 (확정)

- 최초 읽기 시작 시 도서 재고 1권 생성.
- 최초 완독 시 동일 도서 재고 1권 추가.
- 최초 생성된 책부터 즉시 대여 가능하며 완독 여부는 대여 조건이 아니다.

## 미정

독서 상태, 재독 처리, 수정 및 삭제 정책, 통계.

## 재독 및 독후감 보상 (확정)

- 재독 완료 시 동일 도서 재고 1권을 추가한다.
- 독후감 작성 시 해당 도서의 게임 내 가치가 상승한다.
- 독후감 작성은 선택 사항이며 도서 획득 및 대출의 필수 조건이 아니다.
- 가치 상승의 구체적인 효과(대출 선호도, 후원금 등), 수치 및 중복 보상 방지 규칙은 추후 결정한다.

## 장르 분류 체계 (확정)

- 독서 관리와 타이쿤은 동일한 장르 분류 체계를 사용한다.
- 기본 대분류: 문학, 인문, 사회, 역사, 경제·경영, 과학·기술, 자기계발, 예술·문화, 생활, 기타.
- 도서당 대표 장르 1개와 복수의 보조 장르를 지정할 수 있다.
- 대표 장르는 전문성 성장, 손님 선호도 및 네임드 등장 계산에 사용한다.
- 보조 장르는 독서 기록 분류, 검색 및 필터링에 활용하며 전문성 증가에는 반영하지 않는다.
- 세부 장르 목록 및 장르 변경 시 기존 전문성 처리 방식은 추후 결정한다.

## 도서 유형 및 개발 범위 (확정)

- 일반 도서는 페이지, 연재 작품은 회차, 시리즈 도서는 권수, 기타 작품은 직접 입력으로 진행률을 관리한다.
- 종이책과 전자책은 별도 도서 유형이 아닌 매체 속성으로 관리한다.
- 초기 개발은 일반 도서에 집중하며 나머지 유형은 후순위로 둔다.
- 기존 독서 관리 코드의 실제 구현 범위는 추후 확인한다.

## 도서 등록 방식 및 기본 정보 (확정)

- 초기 등록 방식은 직접 입력과 도서 검색 API 연동이다. ISBN 바코드 스캔 및 기존 기록 일괄 가져오기는 후순위로 둔다.
- 필수 항목: 제목, 대표 장르.
- 선택 항목: 저자, 표지 이미지, 보조 장르, 전체 페이지, 출판사, 출판일, ISBN, 매체 유형.
- 검색으로 가져온 정보도 직접 수정 가능하며 검색되지 않는 도서는 직접 등록한다.
- 단순 등록 및 읽고 싶은 책 등록은 게임 도서 획득을 발생시키지 않는다. 독서 시작, 최초 완독, 재독 완료 시 각각 1권을 획득한다.
- 기존 코드 구현 범위 및 도서 검색 API 제공자는 추후 확인한다.

## 독서 상태 및 진행률 (확정)

- 독서 상태는 읽고 싶음, 읽는 중, 일시 중단, 완독, 하차로 구분한다.
- 최초 독서 시작 시 도서 1권, 최초 완독 시 도서 1권 및 장르 전문성을 획득한다.
- 일시 중단 및 하차 시 기존 획득 도서를 유지하며, 독서 재개 시 추가 도서를 지급하지 않는다.
- 진행률 입력은 선택 사항이며 전체 페이지를 몰라도 독서 시작 및 완독 처리가 가능하다.
- 진행률 100% 도달 시 자동 완독하지 않고 사용자가 직접 완독을 확정한다.
- 재독 완료 보상은 기존 확정 규칙을 유지한다.

## 독서 기록 및 이력 (확정)

- 도서 공통 정보와 독서 회차별 이력을 분리한다. 도서 정보는 하나만 유지하고 재독 시 새로운 독서 이력을 생성한다.
- 독서 회차는 자동 부여하며 시작일과 완독일은 자동 입력 및 수정 가능하다.
- 회차별 독서 상태, 현재 페이지(선택), 독서 메모(선택), 리뷰(선택)를 관리한다.
- 게임 보상 지급 이력은 자동 관리하여 중복 지급을 방지한다.
- 일별 독서 시간 및 세부 페이지 변화 기록은 초기 개발 범위에서 제외한다.

## 과거 독서 기록 및 수정·삭제 (확정)

- 과거 독서 기록도 현재 기록과 동일하게 인정한다. 읽고 싶은 책은 보상 없음, 읽는 중인 책은 1권, 과거 최초 완독은 2권, 과거 재독 완료는 회차당 1권을 지급하며 과거 리뷰도 도서 가치 상승에 반영한다.
- 제목·저자 수정 시 게임 도서 정보를 갱신하고 장르 수정 시 전문성을 재계산한다. 날짜 수정은 보상에 영향을 주지 않는다.
- 완독 취소 시 완독 보상을 회수하고 독서 이력 삭제 시 해당 회차 보상을 회수한다. 도서 삭제 시 연결된 게임 도서를 제거한다.
- 보상 지급 이력으로 중복 지급을 방지하고 실제 독서 기록과 게임 데이터의 일관성을 유지한다.
- 대출 중인 도서의 보상 회수 처리 및 이미 획득한 하트·평판의 처리 방식은 추후 결정한다.

## 독서 기록 변경에 따른 도서 회수 (확정)

- 책장, 보관함, 반납 트레이에 있는 회수 대상 도서는 즉시 제거한다.
- 이미 대출 중인 회수 대상 도서는 대출을 취소하지 않고 정상 반납 시점에 제거한다. 반납 트레이에 추가하지 않는다.
- 이미 획득한 하트와 평판은 유지한다.
- 기존 기록 수정·삭제 항목의 대출 중 도서 회수 처리 규칙을 본 항목으로 확정한다.

## 재독 및 리뷰 관리 (확정)

- 재독 시작 시 추가 보상은 없으며 재독 완료 시 도서 1권 및 소량의 전문성을 획득한다.
- 독서 회차별 리뷰 작성이 가능하며 리뷰와 1~5점 별점은 선택 입력이다.
- 리뷰 작성 시 전문성 및 도서 가치가 상승한다. 리뷰 길이에 따른 보상 차등은 없으며 수정 시 추가 보상을 지급하지 않는다.
- 리뷰가 있는 도서는 대출 시 추가 하트를 지급한다. 동일 도서에 여러 리뷰가 있어도 대출 추가 하트 보상은 중첩되지 않는다.
- 구체적인 보상 수치는 추후 결정한다.

## 독서 통계 (확정·후순위)

- 독서 통계는 타이쿤이 아닌 독서 관리 영역의 기능으로 분류한다.
- 기존 독서 기록을 기반으로 자동 집계하며 별도의 게임 보상은 지급하지 않는다.
- 개발 우선순위는 후순위로 두고 구체적인 통계 지표와 화면 설계는 해당 개발 단계에서 결정한다.
- 독서 관리 핵심 기획을 마무리하고 UI/UX 기본 구조 설계로 진행한다.
