## 2026-11-26 — V4 정적 화면

- 버전: v0.1 개발 중
- 작업 목표: PC 웹에서 V4 에셋을 이용해 초기 4슬롯 도서관을 표시한다.
- 완료한 작업: React·Vite·TypeScript·Phaser 프로젝트 구성, 벽·바닥·상태바·데스크·책장·빈 슬롯·반납 트레이 배치, 16:9 비율 유지 설정.
- 수정한 파일: `package.json`, `package-lock.json`, `index.html`, `tsconfig.json`, `vite.config.ts`, `src/`, `.gitignore`, `README.md`, 본 문서.
- 자동 테스트 결과: 별도 단위 테스트 대상 없음. `npm run build`의 타입 검사와 Vite 빌드 통과.
- PC 웹 테스트 결과: Chrome에서 로컬 개발 서버 접속, V4 에셋 로딩과 초기 4슬롯 순서 확인. DevTools 400px 반응형 화면에서도 잘림 없이 16:9 비율 유지 확인. 그 밖의 창 크기 검증은 미실시.

- 미완료 사항: 도서 진열·독서관리·저장·Android 빌드. 최종 논리 해상도 미확정.
