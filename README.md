# BookBloom (북블룸)

실제 독서 활동으로 도서관을 성장시키는 게임 프로젝트입니다. 현재는 V4 에셋 도서관과 임시 독서 관리 화면을 PC 웹에서 검증하는 단계입니다.

## 로컬 실행

Node.js와 npm을 설치한 뒤 프로젝트 루트에서 실행합니다.

```sh
npm install
npm run dev
```

브라우저에서 Vite가 안내하는 로컬 주소를 엽니다. 타입 검사와 빌드는 `npm run build`로 확인합니다. 도서관의 손님·대출은 아직 구현하지 않았고, 임시 독서 관리 화면과 독서 기록·도서관 상태(책장·보관함)의 로컬 저장·복원을 구현했습니다. 640×360은 V4 제작 좌표로 사용 중이며 최종 논리 해상도는 Android 실기기 검증 후 결정합니다.

## 독서 관리 화면(임시)

도서관 화면 오른쪽 아래의 `독서 관리` 버튼으로 독서 관리 화면(세로형 콘텐츠)에 들어가고, 화면 위의 `도서관` 버튼으로 돌아옵니다. 도서 등록(제목·대표 장르 필수)·수정·삭제, 읽고 싶음·시작·일시 중단·재개·하차·완독·재독 시작·완독 취소를 실제 독서 코어로 실행하며, 게임 도서가 늘거나 줄면 결과를 알려 줍니다. 삭제·완독 취소처럼 받은 도서를 회수하는 동작은 확인을 받습니다. 화면을 오가도 독서 기록과 도서관 상태는 유지되고 저장됩니다. 레이아웃·아이콘·디자인은 UI 상세 설계 전이라 정하지 않은 텍스트 중심의 임시 화면이며, Android 방향 전환은 구현하지 않았습니다. 일반 빌드에도 포함됩니다.

## 개발자 테스트 패널

화면 왼쪽 아래의 테스트 패널(`도서 1권`, `도서 10권`, `책장 채우기`, `초기화`)로 도서 획득과 책장 진열을 반복 확인합니다. 패널은 실제 게임 코어(`src/core`)를 호출합니다. 독서 기록과 도서관 상태(책장·보관함)는 변경될 때마다 한 덩어리로 브라우저 IndexedDB에 저장되어 새로고침이나 앱 재실행 후 복원됩니다. 디버그 빌드는 `bookbloom-debug`, 일반 빌드는 `bookbloom` 저장소를 써서 테스트 데이터가 섞이지 않습니다. 도서관 화면 상단 상태바에는 보관함 도서 수(`보관함 N권`)를 임시 문구로 표시하며, 위치와 모양은 UI 명세가 없어 정해지지 않았습니다. 저장된 데이터를 불러오지 못하면 기존 데이터를 보호하려고 게임을 시작하지 않고 오류 안내만 표시합니다. 패널의 `초기화`는 현재 빌드의 저장 상태를 독서 기록까지 포함해 빈 상태로 되돌립니다. 패널의 `도서 등록`·`등록하고 시작`과 도서별 `시작`·`완독`·`재독 시작`·`완독 취소`·`삭제` 버튼은 실제 독서 코어를 호출해 독서 기록에 따라 책장 도서가 늘고 줄어드는 것을 확인하게 합니다. 패널은 `npm run dev`와 `npm run build:debug`(`--mode debug`)에서만 켜집니다. `npm run build`의 일반 빌드에는 패널 코드가 포함되지 않습니다. 책장 용량(`TEMP_SHELF_CAPACITY`)은 기획이 정해지지 않아 선반에 들어가는 개수를 쓰는 임시 상수입니다. 자동 테스트는 `npm test`로 실행합니다.

## Android 디버그 APK

Android Studio와 Android SDK가 설치된 환경에서 `npm run android:sync`로 웹 빌드를 Android 프로젝트에 반영합니다. 테스트 패널이 필요한 터치 검증용 디버그 APK는 `npm run android:sync:debug`로 반영하세요(패널 포함 빌드). 출시용 빌드는 항상 `npm run android:sync`를 사용합니다. 그 뒤 `android/`에서 `gradlew.bat assembleDebug`를 실행하면 `android/app/build/outputs/apk/debug/app-debug.apk`가 생성됩니다. Gradle이 SDK 경로를 찾지 못하면 `ANDROID_HOME`을 SDK 폴더로 지정합니다. `npm run android:open`으로 Android Studio에서 프로젝트를 열 수도 있습니다.

현재 Android 화면은 도서관 검증을 위해 가로 방향으로 고정했습니다. 독서 관리 화면의 Android 방향 전환 방식은 아직 결정하지 않았습니다. 앱 ID는 등록한 도메인 `bookbloom.kro.kr`을 뒤집은 `kr.kro.bookbloom`입니다. 에뮬레이터와 Android 13 실기기에서 설치·화면 표시를 확인했습니다. 긴 화면에서는 640×360 기본 장면을 가운데 두고 벽·바닥·상태바를 좌우로 확장해 앱 영역을 채웁니다. 개발자 패널의 Android 입력은 ADB 터치 명령으로 확인했으며 손가락 직접 조작은 아직 미실시입니다.
